Operating Systems

Understand how operating systems manage processes, memory, devices and files—and apply these concepts to analyse real-world computing systems.

Course code: BTECCE235013 CreditsL–T–P: 3–0–045 Lecture Hours
Explore the course ↓

Course overview

A foundation in the principles, mechanisms and practical applications of contemporary operating systems.

5

Learning units

Introduction, process management, CPU scheduling and deadlock, memory management, and I/O and file management.

45

Teaching hours

Five units planned for nine lecture hours each across a 15-week semester.

100

Total marks

Continuous Internal Evaluation (CIE): 50 marks · End-Semester Examination (ESE): 50 marks.

The course introduces OS structures and services, processes and threads, synchronization, scheduling, deadlocks, memory organization, virtual memory, I/O management and file systems. Case studies connect concepts with Linux and Windows environments.

Course outcomes

By the end of the course, students should be able to:

CO1 · Analyse
Analyse the architecture, functions and services of contemporary operating systems, including RTOS, embedded, mobile and virtualized environments.
CO2 · Apply
Apply process-management and synchronization mechanisms to solve concurrency problems using threads, semaphores, mutexes and monitors.
CO3 · Evaluate
Evaluate CPU-scheduling and deadlock-handling algorithms using performance parameters and resource-allocation scenarios.
CO4 · Analyse
Analyse memory-allocation and virtual-memory techniques using address translation, fragmentation and page-replacement methods.
CO5 · Evaluate
Evaluate I/O-management, disk-scheduling and file-system techniques for efficient secondary-storage utilization.

Unit-wise syllabus

Select a unit to view its topics. Each unit is allocated 9 lectures (20% of the theory syllabus).

Unit I · Introduction to Operating Systems 9 Lectures · 20%
  • Operating-system concepts, hardware interaction, goals, functions, services and system calls.
  • Types of operating systems: batch, multiprogramming, time-sharing, parallel, distributed and real-time.
  • Real-time operating systems: concepts, design, architecture and kernel.
  • Embedded systems: components and design cycle.
  • Hypervisors, virtualization, Docker and Kubernetes.
  • Linux commands, shells, shell programming and AWK.
  • Android operating system.
Unit II · Process Management 9 Lectures · 20%
  • Process concept, process states and process description.
  • Threads and multithreading models; SMP; user-level and kernel-level threads; microkernels.
  • Concurrency and mutual exclusion: hardware, software and operating-system support.
  • Semaphores, mutexes and monitors.
  • Classical synchronization problems: Readers–Writers, Producer–Consumer and Dining Philosophers.
Unit III · CPU Scheduling and Deadlock 9 Lectures · 20%
  • Scheduling types and criteria.
  • FCFS, SJF, Round Robin, Virtual Round Robin and Priority scheduling.
  • Real-time scheduling: EDF, RMS and LLF.
  • Deadlock principles, prevention, avoidance, detection and recovery.
  • Linux and Windows case studies.
Unit IV · Memory Management 9 Lectures · 20%
  • Memory-management requirements; fixed and dynamic partitioning; buddy system.
  • First-fit, best-fit and worst-fit; internal/external fragmentation; swapping and thrashing.
  • Virtual memory, address translation, paging, page tables and TLB.
  • Segmentation and working set.
  • FIFO, LRU and Optimal page-replacement algorithms.
  • Linux and Windows case studies.
Unit V · I/O and File Management 9 Lectures · 20%
  • I/O devices, serial and parallel interfaces, I/O design issues and buffering.
  • Disk scheduling: FCFS, SCAN, C-SCAN and SSTF.
  • File organization, directories, sharing and record blocking.
  • Secondary-storage management, free-space management and security.
  • File-system structure and implementation; memory-mapped files; Linux file systems.

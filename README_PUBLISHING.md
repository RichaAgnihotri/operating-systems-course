# Operating Systems Course Website

This folder contains a single-file responsive course homepage for GitHub Pages.

## Before publishing
1. Open `index.html` and replace the instructor name, official university email, office/consultation hours and any course details that need local confirmation.
2. Verify the assessment breakup against the approved university scheme.
3. If you have lecture PDFs, create a `pdfs/` folder and add files using lowercase names without spaces. Add links in the Learning resources or syllabus sections using relative paths, e.g. `pdfs/unit1-introduction.pdf`.

## Publish with GitHub Pages
1. Sign in to GitHub and create a **public** repository, for example `operating-systems-course`.
2. Upload `index.html` to the repository root (the filename must be exactly `index.html`).
3. Commit the file to the `main` branch.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then Save.
7. Wait for GitHub Pages to deploy. The site URL will be:
   `https://YOUR-USERNAME.github.io/operating-systems-course/`
8. Open the URL on both desktop and phone. Check all navigation and resource links.

## Important
- GitHub Pages hosting is public. Do not publish student personal data, private marks, phone numbers or confidential institutional information.
- Replace placeholders before sharing the link.
- Updates go live after committing the changed file.
